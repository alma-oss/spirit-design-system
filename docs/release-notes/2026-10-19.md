# 2026-10-19 Spirit Design System Release Notes

📢 🚀 🎉 Ahoy, we have a new release with features and improvements. Here we go.

## General Changes

We've made component text easier to translate. Components now accept a single `strings` prop for their built-in labels, and the older individual string props are deprecated. You can move over with the new `component-strings-prop` codemod.

Take `UncontrolledPagination`, which used to need a separate prop for every label:

```tsx
// Before
<UncontrolledPagination
  accessibilityLabel="Page"
  accessibilityLabelNext="Following"
  accessibilityLabelPrevious="Preceding"
  totalPages={10}
/>

// After
<UncontrolledPagination
  strings={{ pageAria: 'Page', nextAria: 'Following', previousAria: 'Preceding' }}
  totalPages={10}
/>
```

The old props keep working for now and will be removed in v6.

You don't have to repeat translations on every instance, either. Provide them once through `I18nProvider` and every component picks them up. Per-instance `strings` still win when you need a one-off override:

```tsx
<I18nProvider translations={{ pagination: { pageAria: 'Page', nextAria: 'Following', previousAria: 'Preceding' } }}>
  <UncontrolledPagination totalPages={10} />
</I18nProvider>
```

To help with the refactor, run the codemod, which turns the deprecated props into `strings`:

```shell
npx @alma-oss/spirit-codemods -p ./src -t v6/web-react/component-strings-prop
```

`Box` also gets more expressive. You can now set `boxShadow` and round individual corners with per-corner border radius, and the new `shadow-<token>` utilities bring the same shadows to plain CSS.

We've also fixed scrolling to a `ScrollView` inside `ModalBody`.
