# 2026-11-12 Spirit Design System Release Notes

📢 🚀 🎉 Ahoy, we have a new release with features and improvements. Here we go.

## General Changes

Translating components is now much simpler. Components accept a single `strings` prop for all their built-in labels. You can also provide translations once through `I18nProvider`, and per-instance `strings` still win when you need a one-off override. The old individual string props are deprecated but keep working until v6, and the new `component-strings-prop` codemod moves your code over for you.

`Box` gets more expressive, too: you can now add depth with the new `boxShadow` prop and round individual corners with per-corner border radius. The matching `shadow-<token>` utilities bring the same shadows to plain CSS. We've also fixed scrolling to a `ScrollView` inside `ModalBody`.
