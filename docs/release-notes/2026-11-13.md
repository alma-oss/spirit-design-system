# 2026-11-13 Spirit Design System Release Notes

📢 🚀 🎉 Ahoy, we have a new release with features and improvements. Here we go.

## General Changes

This release makes groups of actions easier to use with the keyboard and makes forms more consistent. The new `Toolbar` component puts three or more actions into a single Tab stop with arrow-key navigation, and `Navigation` now fits inside it. The rest of the form fields also get a `size` prop, so you can size the labels of `Checkbox`, `Radio`, `Toggle`, `Slider`, `FileUpload`, `FieldGroup` and `ProgressBar` the same way as the other fields. For now, the controls themselves keep their current dimensions. We've also added the experimental `UNSTABLE_EyebrowText` for short labels above headings. On the token side, shadow lengths are now exposed as CSS custom properties, so themes can change the shape of a shadow without forking the token.

Heads-up for `UNSTABLE_Combobox` users: the built-in `hasClearButton` toggle is gone. Instead, you add your own icons or clear button with the new `startSlot` and `endSlot` props and `InputAddon`, and you can clear the selection by calling `removeAll()` on the ref.
