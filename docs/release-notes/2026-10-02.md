# 2026-10-02 Spirit Design System Release Notes

📢 🚀 🎉 Ahoy, we have a new release with features and improvements. Here we go.

## General Changes

We've added two new components you can start using right away: `ProgressBar` for determinate progress (including file-upload flows), and `UNSTABLE_Tile` for a decorated region that sits between a plain `Box` and a full `Card`. Try `UNSTABLE_Tile` and tell us how it feels — it's unstable on purpose.

Help next to a field label is now a first-class pattern. The new `ContextualHelp` component, plus the **contextualHelp** prop on `UNSTABLE_Combobox` and `UNSTABLE_Picker`, keeps extra explanation out of the `<label>` so the field stays accessible. `Skeleton` can follow a fluid parent with percentage width and height (a number still becomes rem), `Item` gained size variants, and `Label` now has its own size scale — prefer those over bare typography on labels.

## What's Next 🔮

- **Contextual help on more fields**
  The **contextualHelp** prop is on `UNSTABLE_Combobox` and `UNSTABLE_Picker` today. We plan to add it to other form components as well.

- **Combobox slots**
  `UNSTABLE_Combobox` is getting **startSlot** and **endSlot**, so you can place a leading icon (or other content) the same way you already do on other form fields.

- **Box radius and shadow**
  Per-corner radius overrides and a real shadow story for `Box` (and the surfaces built on it), so you don't have to hand-roll those styles.

- **Illustrations as assets**
  Illustrations will load as their own asset set, separate from the icon pack, so products can opt in without pulling everything.

- **List**
  A dedicated `List` component is in design, aimed at structured option and content lists instead of one-off markup.

- **Non-modal Dialog**
  React `Dialog` will support a non-modal mode, so you can use lighter overlays that don't lock the rest of the page.
