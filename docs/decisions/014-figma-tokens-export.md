# Figma Tokens Export

Date: 2026-08-25

Status: accepted

## Context

Spirit design tokens live in Figma as variables and styles. The committed SCSS and TypeScript packages were generated by a Supernova exporter (`exporters/tokens`). That added an intermediary, made values lag behind Figma, and tied generation to a host we are leaving.

Figma’s variables REST API is available on Enterprise with `file_variables:read`. Style metadata is a separate endpoint. Style properties and variable bindings are on the style nodes.

## Decision

- Design tokens are synchronized from the Figma REST API with `@alma-oss/spirit-figma-tokens-exporter`. Figma is a source adapter. Configuration, the CLI, and disk mirroring stay independent of Figma.
- One brand is one Figma file, configured as a `tokens.sources` entry. `theme-light-on-brand` is a theme mode, not a brand.
- The adapter emits the domain tokens the SCSS and TypeScript writers already consume. Figma response shapes do not enter the writers.
- Output must match the existing file tree, names, object shapes, ordering, and formatting for tokens the previous exporter produced. Allowed differences are Figma-authoritative values, the provenance comment (`Figma` instead of `Supernova`), and tokens that exist in Figma but were absent from the Supernova dump.
- Keep `exporters/tokens` until the next major release. Supernova is not the generator of record.

## Consequences

- Token delivery no longer depends on Supernova or a local Figma plugin for the happy path.
- Authors need `FIGMA_ACCESS_TOKEN` with file content and local variable scopes. The file key is not a secret.
- Malformed names, ambiguous scopes, missing aliases, and unmapped font families fail the export with aggregated diagnostics, before the output directory is changed.
- The `Primitives` and remote `Brand` collections stay alias sources and are not generated. Unused paint styles are reported and omitted.
- `figma-*` variables and typography styles containing `Link` or `Italic` stay excluded.
- Generated `js/` and `scss/` files remain the reviewable artifact.
