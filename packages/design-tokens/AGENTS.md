# Spirit Design Tokens Agent Instructions

## Package Folder

- `src/` holds the tokens generated by Supernova. Never edit it by hand.
  Change a token in Figma and Supernova, then commit the exported result.
- `cjs/`, `esm/`, `umd/`, `scss/`, and `types/` are build output. Do not edit or commit them.

## Rules

- Do not hard-code a value that a token already provides.
- Renaming or removing a token is a breaking change. Follow the `spirit:breaking-change-checklist` skill.
- Before finishing, run `yarn workspace @alma-oss/spirit-design-tokens test` and `yarn workspace @alma-oss/spirit-design-tokens types`.
  Together they run lint and types.
