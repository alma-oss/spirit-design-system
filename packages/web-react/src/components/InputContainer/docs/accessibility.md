## Accessibility

The majority of accessibility issues are already guaranteed by implementation. In the case of modifications or composition in HTML, please follow the recommendations below.

- InputContainer itself is not interactive.

- Keyboard focus belongs to the contained input or interactive elements inside InputAddons.

- Decorative addons should not receive focus.

- Interactive addons must be independently keyboard accessible

- Interactive elements must have clear, accessible names.

- Input Details content should remain readable and understandable when announced by assistive technologies.

- Ensure sufficient contrast for supporting text and links.
