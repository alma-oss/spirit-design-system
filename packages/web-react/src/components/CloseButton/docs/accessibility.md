## **Accessibility**

The majority of accessibility issues are already guaranteed by implementation. In the case of modifications or composition in HTML, please follow these recommendations.

- CloseButton must be keyboard accessible.

- Always provide an accessible label describing the action (for example "Close dialog" or "Remove item").

- Do not rely solely on the close icon to communicate its purpose.

- Focus should be managed appropriately after the related element is dismissed.
