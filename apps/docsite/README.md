# Documentation Website

## Canonical Pages

Until Cutover, `yarn supernova:extract` (from the monorepo root) overwrites Owned Paths under [`content/`](./content). See [scripts/supernova-extract/README.md](../../scripts/supernova-extract/README.md).

- Component Tab Pages (`content/components/<slug>/{overview,design,accessibility,figma}.md`) feed the component app shell.
- Other sections are filesystem routes with a section sidebar (`/introduction`, `/design`, `/development`, `/migrations`, `/releases`).
- `/migrations` and `/releases` render existing repository markdown (`docs/migrations`, package CHANGELOGs) instead of extracted copies.
- `/` and `/components` stay generated by the app, not by extract.
