# Documentation Website

## Canonical Pages

Until Cutover, `yarn supernova:extract` (from the monorepo root) overwrites repository-relative Owned Paths. See [scripts/supernova-extract/README.md](../../scripts/supernova-extract/README.md).

- Component Tab Pages (`packages/web-react/src/components/<Component>/docs/{overview,design,accessibility,figma}.md`) feed the component app shell.
- Introduction, design, development, and the migrations landing are read from the repository [`docs/`](../../docs) tree.
- Other sections are filesystem routes with a section sidebar (`/introduction`, `/design`, `/development`, `/migrations`, `/releases`).
- Nested `/migrations` routes and `/releases` render existing repository markdown (`docs/migrations`, package CHANGELOGs) instead of extracted copies. The `/migrations` landing remains extracted.
- `/` and `/components` stay generated by the app, not by extract.
