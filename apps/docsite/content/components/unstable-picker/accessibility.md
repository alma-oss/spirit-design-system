## Accessibility

The majority of accessibility issues are already guaranteed by implementation. In the case of modifications or composition in HTML, please follow the recommendations below.

- Picker must be keyboard accessible

- Users must be able to:

- open and close dropdown via keyboard

- navigate options

- select and deselect items

- remove selected Tags

- Each Tag remove action must have an accessible label (for example “Remove item”)

- Dropdown options must be properly announced (role and state)

- Focus management must be clear and predictable
