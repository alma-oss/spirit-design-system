## Accessibility

The majority of accessibility issues are already guaranteed by implementation. In the case of modifications or composition in HTML, please follow the recommendations below.

- All functionality must be available using the keyboard.

- Suggestions should be announced appropriately to assistive technologies.

- Selected values must remain accessible when rendered as Tags.

- Focus management between input, overlay and selected values must be predictable.

- The component should follow the ARIA Combobox pattern.
