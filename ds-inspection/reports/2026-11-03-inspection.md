# Multi-Point Inspection Report — Spirit Design System

_Inspected: 2026-11-03 · Technician: Claude (Sonnet 5.5), five parallel read-only station agents plus spot-verification · Previous inspection: first inspection_
_Vehicle profile: `ds-inspection/GARAGE.md` (checked in 2026-11-03)_

## The short version

Spirit is in good running order: no red lights, two greens and eight yellows. The engine (component APIs, tokens, tests, release automation) is strong for a team this size. The yellows cluster around the seams: things that exist but aren't yet watched, announced or measured. Three findings carry the most weight:

1. **Contrast is the one open accessibility hole.** `text-tertiary` (#7f7f7f) is 3.93:1 on the page surface and the default interactive border (#bfbfbf) is 1.81:1, and the Modal e2e spec has axe `color-contrast` switched off (DS-2317). Because that suppression is in place, CI cannot catch contrast regressions today. A consumer's own e2e already tripped on the same tertiary text color on Prace.cz. [verified]
2. **Drift between Figma, code tokens and docs is caught by people, not machines.** Tokens still travel through Supernova (ADR 013 leaves its replacement undecided), there is no token-parity or Code Connect check in CI, and visual regression only runs on main or with a PR label. As consumers grow, this is the seam that will hurt first. [verified]
3. **The backlog and adoption are unmeasured.** 391 DS issues are open, 125 (32%) untouched for 180+ days, 78% without a Component, and the only adoption number is about 4k npm downloads a month. The support loop itself is fast and alive (a weekly rota, 48h reaction target, bugs closed in a median of about 30 days). [verified]

The single most important next step: **fix contrast at the token source (close DS-2317) and re-enable axe `color-contrast` in the e2e specs**, then make visual tests run automatically on token and SCSS pull requests. Together they turn two silent risks into CI failures.

**Overall: 69/100** — a conversation starter, not a grade. Fix the reds (none), schedule the yellows, re-run on a cadence.
