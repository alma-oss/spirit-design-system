## 🟡 Schedule (yellows)

Ordered by leverage: items 1–3 turn silent risks into CI failures, items 4–6 protect growth in consumers, items 7–10 are hygiene.

### 1. Close the contrast gap and re-enable the axe rule

- **Station:** 3, Accessibility · **Evidence:** [verified] `text-tertiary` #7f7f7f is 3.93:1 and `border-interactive-state-default` #bfbfbf is 1.81:1 on `#fdfdfc` (theme-light-default); `tests/e2e/a11y/modal.spec.ts` disables `color-contrast` (DS-2317)
- **First move:** retune the two tokens at the source (text ≥ 4.5:1, interactive border ≥ 3:1 if it is the only field boundary cue), check the warning-with-text pairing, then remove the `color-contrast` suppression. Decide what this means for brand themes first, since a token change is visible in every brand.
- **Done when:** the e2e axe specs run with `color-contrast` enabled and pass on every PR; DS-2317 is closed.
- **Effort:** M
- **Suggested timing:** this sprint. Designer sign-off is needed on the new values.
- **AI assist:** the agent can compute the replacement values per brand mode and list every component using the two tokens. A human picks the visual direction.

### 2. Make visual tests automatic for token and SCSS pull requests

- **Done when:** a token PR cannot merge without a visual run, and the run is part of the required checks.
- **Effort:** S
- **Suggested timing:** this sprint. Do it before item 1 merges, so the token change is covered.

### 3. Token parity check, plus an ADR for life after Supernova

### 4. Add a naming guardrail and tidy the known drift

- **Station:** 4, Shared language · **Evidence:** [verified] no naming lint, dictionary-conformance test or Figma-vs-code validator; drifts: `File.onDismiss` vs `onClose`, Avatar `Type` enum vs `isSquare`, Pill models disabled twice, mixed `NEW`/`OLD` suffixes and sub-component naming in Figma, `Pricing table`/`Toast Bar` vs `PricingPlan`/`Toast`
- **First move:** add `figma connect publish --dry-run` as a CI gate and an ESLint rule or test for `is*`/`on*` and dictionary conformance. Then normalize the drifts (prop renames behind a codemod, per the breaking-change checklist).
- **Done when:** CI fails on a new naming drift; the listed drifts are resolved or recorded as deliberate.
- **Effort:** M
- **Suggested timing:** this quarter.
- **AI assist:** an LLM can produce the full consistency report across the 426 variables, Figma set and property names, and component props in one pass. The team agrees the rule.
